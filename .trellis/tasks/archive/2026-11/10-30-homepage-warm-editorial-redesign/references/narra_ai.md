## 二、 直接复制给 AI 的主提示词（Master Prompt）

> 💡 **使用方法**：复制下方分割线内的全部内容，直接发给你的 AI 编程助手。

***

你现在是一位资深前端架构师兼艺术级 UI/UX 工程师。我需要将我当前项目中的首页组件（现有代码）按照参考文件 `hero-redesign-reference.html` 的视觉设计、布局结构与交互动效进行重构升级。

请严格遵循以下 **4 大核心原则** 进行代码迁移与重构：

### 1. 铁律：保留原有业务逻辑，剔除演示辅助元素
* **必须保留**：我原有首页组件中的真实状态绑定（如：用户头像、剩余积分、签到状态、宠物开关状态、退出登录事件、路由跳转链接 `router-link` / `Link`、以及画廊列表与点击事件的真实接口数据绑定）。
* **必须剔除（重要）**：参考文件 `hero-redesign-reference.html` 顶部的深色预览横幅（“视觉重构与动态光影预览版”）以及页面中所有的 `.design-annotation` 批注气泡（即“优化① ~ 优化⑥”提示条）仅用于设计评审，**绝对不要**将它们写进正式业务代码中！

### 2. 全局设计规范（Design Tokens）与质感升级
请将页面从原有的“冷白 SaaS 贴片感”全面切换为参考文件中的**「暖调画纸策展质感（Warm Editorial Canvas）」**：
* **字体引入**：确保引入 Google Fonts 的 `Cormorant Garamond`（英文衬线）、`Noto Serif SC`（中文宋体衬线）和 `Plus Jakarta Sans`（现代无衬线）。
* **色彩体系（Tailwind 配置或 CSS 变量）**：
  * 主背景燕麦画纸色 (`paper-bg`): `#F6F2EB`（搭配参考文件中的细腻径向光晕与 `.paper-grain` 噪点）
  * 二屏暖亚麻容器 (`paper-linen`): `#EDE6DB`
  * 卡片柔光暖白 (`paper-card`): `#FAF8F4`（**严禁使用刺眼的 `#FFFFFF` 纯白背景与厚重黑阴影**）
  * 暖调细描边 (`paper-border`): `#DFD5C7`
  * 主标题深暖墨色 (`paper-ink`): `#1F1B18`
  * 次要正文暖灰 (`paper-muted`): `#6E655C`
  * 叙事陶土橙红 (`paper-accent`): `#C85A32`
  * 丁达尔暖金 (`paper-gold`): `#D49B54`
* **符号系统统一**：移除原页面中所有极客代码风的 `//` 双斜杠眉题，统一替换为参考文件中的画廊策展编号风格（如 `01 — CORE CAPABILITIES · 严选核心能力`、`02 — CURATED WORKS · 佳作展映`）。

### 3. 各楼层结构与排版重构要求
1. **顶部导航栏（Header）**：
   * 采用 `sticky top-0 backdrop-blur-md bg-[#F6F2EB]/85` 暖调毛玻璃效果，胶囊菜单使用 `#EFEAE1/90` 暖色底。
2. **第一屏（Hero Section）**：
   * **左侧大标题**：修复“中，”字单独成行的孤字问题，严格分为两行：`在“叙事性”的光影中，` / `编织属于你的灵感画面`。其中`“叙事性”`使用中文衬线体（`Noto Serif SC`）、陶土橙红色并附带底部手绘弧线 SVG。
   * **数据统计栏合并（关键改动）**：删除原页面中独立夹在第二屏与第三屏之间的三栏数据白框，将 `150,000+`、`120+`、`< 4.2s` 移动到首屏左侧按钮正下方，采用衬线体大数字 + 载入平滑递增动画（Count-up）。
   * **右侧交互画布**：去掉原有的 macOS 红黄绿窗口头，改为参考文件中的暖色画框，包含顶部 3 个风格切换胶囊（胶片光影 / 绘本叙事 / 东方美学）、中央局部重绘呼吸扫描框（`.inpaint-ring` & `.inpaint-scan`）、以及底部带打字机逐字输入动效（Typewriter）的毛玻璃 Prompt 浮层。
3. **第二屏（Core Capabilities 核心能力）**：
   * 外部包裹 `rounded-[32px] bg-[#EDE6DB]/85` 暖亚麻色大圆角容器，建立清晰的章节节奏。
   * 4 张卡片不再只有纯文字，需完整还原参考文件中每张卡片底部的**微缩视觉示意组件**（① 自动轮播高亮的灵感词胶囊、② `v1 → v2 → v3` 版本演进节点、③ 可点击切换灵感的数字宠物互动条、④ `200 OK` 极速 API 响应状态条）。
4. **第三屏（Exhibitions 社区精选画廊）与页脚**：
   * 移除原页面中切在「社区精选」标题与图片网格之间的突兀水平分割线。
   * **画廊卡片降噪**：默认状态仅保留轻柔底部暗角、作品标题、作者与右上角点赞；当鼠标 Hover 悬停时，再平滑向上展开毛玻璃抽屉展示完整 Prompt、「复制灵感词」与「做同款」按钮。
   * **长页收尾**：在画廊底部补充「漫游全部作品」引导按钮，并补齐参考文件底部的深暖咖色（`#1F1B18`）人文页脚（Footer），解决长页面滚到底部戛然而止的问题。

### 4. 必须完整迁移的 6 组核心动效
请将参考文件 `<style>` 和 `<script>` 中的以下动效完整转化为当前前端框架（Vue / React）的响应式逻辑或生命周期钩子：
1. **首屏画布 3D 视差倾斜**（随鼠标计算 `rotateX` / `rotateY`）与 **Canvas 丁达尔暖金浮尘粒子动画**。
2. **首屏场景切换时的图片平滑过渡 + Prompt 打字机逐字输出动画**。
3. **首屏三组核心数据的 `requestAnimationFrame` 缓动数字递增（Count-up）**。
4. **第二屏 4 张卡片的鼠标追光效果（Spotlight）**：通过追踪鼠标坐标动态更新卡片的 CSS 变量 `--mouse-x` 与 `--mouse-y`。
5. **第三屏社区精选画廊卡片的 3D 视差悬浮与多层景深位移**：
   * 卡片整体：`perspective(950px) rotateX(...) rotateY(...) scale3d(1.02, 1.02, 1.02)`。
   * 动态暖金画框反光层（`.gallery-card-glare`）：跟随 `--glare-x` 与 `--glare-y` 移动。
   * 多层景深：内部图片做反向微位移（`scale(1.08) translate3d(...)`），底部信息层做正向微位移（`translate3d(..., ..., 24px)`），鼠标移出时平滑复位。
6. **滚动楼层渐显（IntersectionObserver `.reveal-section`）** 与 **画廊卡片阶梯级联入场动画（`.gallery-item-anim`）**。

请先输出重构后的完整组件代码，并确保所有定时器和事件监听在组件卸载（`onUnmounted` / `useEffect cleanup`）时正确清理，避免内存泄漏。

## 三、 进阶小贴士：如果代码较长，如何防止 AI 偷懒截断？

如果你使用的是 Vue 或 React，且单文件原本就有很多业务代码，一次性让 AI 输出全部代码可能会触发模型的输出长度限制。此时你可以在发送完上面的提示词后，补上一句：

* **分步生成指令**：
  > “为了保证代码完整不省略，请分两步输出：第一步先输出完整的 `<template>`（或 JSX 结构）与 `<style>` 样式；等我确认后，第二步再输出完整的 `<script>` 逻辑与动效绑定代码。严禁使用 `// ... 省略其余代码`。”
