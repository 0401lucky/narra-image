## 2. Requested Fonts Are Available

Reference font request (`references/narra_image.html:12`):

```text
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,500;0,600;0,700;1,400;1,600&family=Noto+Serif+SC:wght@500;600;700&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap
```

Fetched successfully using a modern Chrome user agent: 200, `text/css`, 354976 bytes. Response structure:

| Family | Requested styles/weights | CSS blocks / unique WOFF2 URLs |
| --- | --- | --- |
| Cormorant Garamond | Normal 500/600/700; italic 400/600 | 25 / 10 |
| Noto Serif SC | Normal 500/600/700 | 303 / 101 |
| Plus Jakarta Sans | Normal 400/500/600/700 | 16 / 4 |

Duplicate URLs appear in multiple weight rules; preserve the supplied declarations unless the actual font axes are separately verified. Noto Serif SC is split by `unicode-range`, not a single small Latin file. Fetching only its Latin subset would not supply Chinese typography.

Sample successful downloads:

- Cormorant normal Latin: `https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK.woff2`, 37640 bytes.
- Cormorant italic Latin: `https://fonts.gstatic.com/s/cormorantgaramond/v21/co3ZmX5slCNuHLi8bLeY9MK7whWMhyjYrEtImSo.woff2`, 39260 bytes.
- Plus Jakarta Sans Latin: `https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2`, 27348 bytes.
- Noto Serif SC Chinese range containing U+53D9: `https://fonts.gstatic.com/s/notoserifsc/v36/H4chBXePl9DZ0Xe7gG9cyOj7oqP0dTpxZbB9E9gjjmzKvaeKHUTtJDWv3z-us4bxD8F5og.106.woff2`, 81652 bytes.

Each sample returned 200 with a WOFF2 content type. Its `wOF2` signature and declared file length match. No browser font render was performed. Installed Python fontTools could not decode WOFF2 because the optional Brotli module is absent; no package was installed to work around this.

### Delivery Recommendation

- Self-host official, unmodified WOFF2 files and their CSS under a homepage-specific asset location after implementation approval. Pin filenames/content hashes and retain license notices; do not fetch fonts during a production build or require visitor access to Google Fonts.
- Preserve `font-style`, `font-weight`, `font-display: swap` and Chinese `unicode-range` rules. Deduplicate identical downloaded files, not the meaning of CSS declarations. Avoid manufacturing a tiny fixed-text subset that later drops glyphs from dynamic content.
- Scope font-family application to the homepage wrapper and its explicit header/footer variant. Do not rename global fallback variables or recolor other routes to mimic font installation.
- Avoid eagerly preloading all 101 Chinese shards; only preload verified first-screen needs, and let unicode-range matching load the rest on demand. Measure browser requests/layout shift later; this research provides no bundle or performance result.
- Keep the reference's distinction between expressive English/Chinese serif headings and the sans-serif UI body. The reference deliberately uses local Chinese sans fallbacks after Plus Jakarta Sans.

## 3. License Evidence And Limits

All three official font license files state SIL Open Font License 1.1:

- `https://raw.githubusercontent.com/google/fonts/main/ofl/cormorantgaramond/OFL.txt`
- `https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/OFL.txt`
- `https://raw.githubusercontent.com/google/fonts/main/ofl/plusjakartasans/OFL.txt`

The copied notices identify the Cormorant Project Authors, Google, and the Plus Jakarta Sans Project Authors respectively. Preserve the full copyright and license text with redistributed fonts. The OFL allows bundling/redistribution subject to its conditions; it does not mean stripping notices, selling the font alone, or changing reserved font names is unrestricted. Prefer unmodified official binaries.

`https://unsplash.com/license` returned 200. Its text permits downloading and using images, including commercially, without mandatory attribution; it prohibits selling unmodified images and compiling images to replicate a similar/competing image service. Attribution is appreciated. This supports ordinary illustrative placement subject to the actual image's rights; it does not establish third-party trademark/person/property permissions or the provenance of the broken URL. Do not assert legal clearance beyond this evidence.

If original/candidate Unsplash assets are retained, record the exact image URL, available photographer/source metadata, license source and retrieval date. Do not copy the prototype's generic copyright sentence as a new legal policy, and do not overwrite existing `THIRD_PARTY_NOTICES.md` contributions from unrelated work.
